# אורן הובלות ומשאיות

פרויקט React/Vite שהוסב מתבנית מוסך לאתר למשרד הובלות ושינוע משאיות.

## מה שונה
- מיתוג מלא לעסק הובלות.
- Hero עם מסר של הובלות ושינוע בפריסה ארצית.
- שירותים: הובלות במשאיות, מפעלים ומחסנים, אתרי בנייה, קווים קבועים, מטענים כבדים והובלות דחופות.
- טופס "קבלת הצעת מחיר" עם שדות שמתאימים להובלה.
- גלריה ותמונות בנושא משאיות.
- עמוד אודות מותאם לחברת הובלה.
- המלצות של לקוחות עסקיים.
- מסך ניהול הפניות עודכן לבקשות הצעת מחיר ולקטגוריות הובלה.
- נשמר מנגנון שמירת הפניות הקיים ב-MockAPI.

## הפעלה
```bash
npm install
npm run dev
```

לבנייה:
```bash
npm run build
```

## לפני עלייה לאוויר
יש להחליף ב-`src/data/siteConfig.js`:
- שם העסק
- טלפון
- אימייל
- כתובת/אזור שירות
- שעות פעילות
- תמונות
- טקסטים

מומלץ גם להחליף את `API_URL` ב-`src/components/Contact.jsx` וב-`src/pages/Admin.jsx` לשרת/מסד הנתונים האמיתי של העסק.
